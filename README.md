# Near Expiry Shop (DXB)

Professional marketing website for Near Expiry Shop — a Dubai-based retail business offering near-expiry products at affordable prices.

## Tech stack

- React + Vite
- Tailwind CSS v4
- Lucide React icons

## Getting started

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal (usually `http://localhost:5173`).

## Production build

```bash
npm run build
npm run preview
```

## Editing business content

Update `src/data/business.js` for:

- Contact details
- Address and map link
- Navigation
- Category placeholders
- Sample product placeholders
- Feature and step copy

Sample products are labeled as placeholders and should be replaced with real inventory when available.

## Deploy

Any static host works after `npm run build` — for example Netlify, Vercel, Cloudflare Pages, or GitHub Pages. Publish the `dist` folder.
